03 / GO LIVE

Three steps to publish.

This is a static website, so you do not need Node.js or a backend to host the landing page.

STEP 01 — FILES

Keep index.html

Commit this file to the root of your SOURAJIT-VFX-Mini repository.

STEP 02 — PAGES

Enable GitHub Pages

Open Settings → Pages. Choose Deploy from a branch, select main and /(root), then save.

STEP 03 — LIVE

Visit your site

GitHub will show the published URL in Pages settings after deployment completes. A short wait may be needed.
